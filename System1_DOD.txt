Core Objective of System 01Transform ordinary, cluttered, poorly lit smartphone photographs into clean, faithful, marketplace-ready product images without distorting the physical product, while exposing an asynchronous API that Amar’s Flutter app can consume seamlessly.2. The "Definition of Done" Checklist (When You Can Call System 01 Complete)A. Functional Pipeline Capabilities (Stages A–H)Non-Destructive Ingestion (Stage A): Accepts JPEG, PNG, and WebP images (including multi-angle batches of 2–5 photos) and saves the raw upload untouched in object storage before any processing begins.   Actionable Quality Gate (Stage B): Evaluates sharpness (Laplacian variance), exposure/glare, framing/size, and occlusion. Rejects unusable captures with standardized, seller-friendly feedback codes (BLURRY, TOO_DARK, TOO_SMALL, CUT_OFF_FRAME) rather than raw numerical scores.   Aspect-Ratio-Safe Segmentation & Matting (Stages C & D): Detects the primary product bounding box and extracts a clean alpha matte using BiRefNet-HR (preserving native aspect ratios via padding so tall sarees or wide items never squash).   Interactive Fallback (Stage D Fallback): Supports a single (x, y) normalized coordinate tap prompt via SAM 2 to refine masks on difficult edges (thin jewellery chains, loose handloom threads, hollow handles).   Immutable Product Master (Stage E): Compiles and persists the write-protected asset bundle (original/, masks/, cutouts/, marketplace/, thumbnails/, and metadata/).   Deterministic Photographic Polish (Stage F): Fixes phone camera flaws—stripping indoor yellow/fluorescent casts (auto white balance), lifting dark midtones (gamma correction), reducing sensor grain (bilateral denoising), and applying subtle unsharp masking—without using generative AI.   Marketplace Rendering & Grounding (Stage G): Centers the calibrated cutout on a clean neutral/white canvas (1200×1200 px, 60%–80% visual dominance) with a mathematically generated contact occlusion shadow anchored at the product’s base so it never looks like a floating sticker.   Automated Fidelity Verification (Stage H): Automatically verifies that the final marketplace image preserves the original product's shape, boundaries, and color spectrum before approving it for seller preview.
